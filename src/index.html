Guidance & frequently asked questions

Practical tips to move from a test expression into a real flow.

Can I paste a Power Automate expression directly?

Yes. Expressions may start with @, or be written without it as in the expression designer. You can also test text interpolation using @{...}. Some supported syntax such as nested functions and null-safe bracket access works with supplied JSON context.

How do I mock trigger and action data?

Choose “Mock context”, edit the JSON, and use triggerBody()?['field'], body('Action_name')?['field'], variables('name') or outputs('Action_name')?['property']. Action keys should match the names in your expression.

Does this run a Microsoft Power Automate flow?

No. This is an independent offline simulator for a documented subset, not a Microsoft product or authoritative WDL engine. It cannot call connectors, access your tenant, or reproduce all runtime coercion and date/time functionality. Always test your final expression in a real flow.

Are expressions uploaded, stored or sent to a service?

No. The application does not submit expressions or context to a server, and does not save them between sessions. The online page fetches shared brand components and imagery; the offline HTML makes no application network requests.

What if my function is not listed?

Use Microsoft's official function reference and validate in Power Automate. The evaluator will tell you a function is not supported instead of guessing at its result.
